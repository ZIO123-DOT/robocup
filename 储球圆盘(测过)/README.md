# 储球圆盘：中空云台电机 + AS5600 闭环定位

目标板：正点原子 STM32F103ZET6 核心板 V1.6。

本工程参考 `final` 中中空云台的三路 PWM 六步换相与 AS5600 角度反馈代码，专门用于第二个中空云台电机驱动储球圆盘。上电后所有 PWM 为 0，电机不会自行转动。

## 引脚

- PC7：TIM8_CH2，储球圆盘功率级 U 控制输入。
- PC8：TIM8_CH3，储球圆盘功率级 V 控制输入。
- PC9：TIM8_CH4，储球圆盘功率级 W 控制输入。
- PA1：储球圆盘 AS5600 PWM OUT 输入，DWT 测量占空比。
- PA9/PA10：USART1 调试串口。
- PA13/PA14：ST-Link SWD。

PC7/PC8/PC9 只能连接三相功率驱动板的控制输入，不能直接连接电机 U/V/W。

## 串口命令

USART1：115200、8N1、无流控。

| 命令 | 作用 |
|---|---|
| `read` | 读取并打印 AS5600 当前角度 |
| `angle90` 或 `90` | 闭环转到 90°；范围 0～360° |
| `cw1` | 开环顺时针运行 1 个电气周期，仅用于检查相序 |
| `ccw1` | 开环逆时针运行 1 个电气周期，仅用于检查相序 |
| `stop` | 立即把三路 PWM 关闭 |
| `help` | 打印命令说明 |

当前实物只有 `cw` 能稳定带动圆盘，因此闭环定位采用 CW 单方向找目标，AS5600角度会持续减小并在目标附近停止。该模式最多转一圈，不能保证走最短路径，但能避开 `ccw` 堵转。换相先恢复为此前 `cw3` 已验证的25ms/步节奏，接近目标时再降低速度；连续三次进入 ±3° 才报告成功。如果2.5秒内角度变化不足1°、AS5600无有效反馈或运行超过20秒，程序会关闭PWM并打印具体失败原因。
