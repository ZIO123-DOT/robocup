# 来源与差异说明

## 参考来源

储球圆盘的六步换相顺序、三路 PWM 中心值和 AS5600 角度换算，参考桌面 `final` 中已存在的中空云台模块。USART1 的无换行超时识别和运行期间 `stop` 检测参考 `wheelsound.zip`。

## 与中央云台的区别

中央云台占用 PA3、PA6、PA7 和 PC6；储球圆盘改用 TIM8_CH2/CH3/CH4 的 PC7、PC8、PC9，第二只 AS5600 改用 PA1，不重复任何中央云台引脚。

AS5600 使用 GPIO+DWT 测量 PWM，不占用 TIM5 输入捕获，因此不会干扰 PA2/TIM5_CH3 的爪子舵机。

## 新增保护

- 上电三路 PWM 保持 0；
- 只有收到角度或点动命令才驱动；
- 根据实测结果，`cw` 可稳定减小角度而 `ccw` 堵转；闭环暂时只沿 CW 单方向定位，最多转一圈；
- 接近目标时降低换相速度，并要求连续三次进入 ±3°；
- AS5600 失效、20 秒超时、方向反转过多或收到 `stop` 时关闭 PWM。

这份工程已完成软件编译验证，但储球圆盘功率级、相序、磁铁方向和负载尚未实机验证。
