# 储球圆盘接线引脚表

## STM32 与三相功率驱动板

| STM32F103ZET6 | 功能 | 连接 |
|---|---|---|
| PC7 / TIM8_CH2 | PWM-U | 三相功率驱动板 U 控制输入 |
| PC8 / TIM8_CH3 | PWM-V | 三相功率驱动板 V 控制输入 |
| PC9 / TIM8_CH4 | PWM-W | 三相功率驱动板 W 控制输入 |
| GND | 信号地 | 三相功率驱动板控制地 |

中空云台电机的三根 U/V/W 动力线接三相功率驱动板的电机输出端。严禁把电机 U/V/W 直接接到 STM32。

储球圆盘三相功率级必须与中央云台使用不同的驱动板。驱动板电源按电机和功率级额定值连接，不能从 STM32 5 V 引脚给电机供电。

## AS5600

| AS5600 | 连接 |
|---|---|
| PWM OUT | PA1；如果输出为 5 V，先分压/转换到 3.3 V |
| GND | STM32 与功率驱动板公共 GND |
| VCC | 按 AS5600 模块标注接 3.3 V 或 5 V |

AS5600 的 PWM 是传感器输出，方向为 AS5600→STM32。磁铁必须对准芯片中心，间距和磁化方向符合模块要求。

## 串口与下载

| 功能 | STM32 | 外部设备 |
|---|---|---|
| USART1 TX | PA9 | USB-TTL RX |
| USART1 RX | PA10 | USB-TTL TX |
| 串口地 | GND | USB-TTL GND |
| SWDIO | PA13 | ST-Link SWDIO |
| SWCLK | PA14 | ST-Link SWCLK |

普通 ST-Link V2 不提供串口功能。USART1 调试仍需要 USB-TTL；如果板载 CH340 已损坏并拉低 PA9/PA10，应先排除硬件短路。

## 与整车引脚的关系

- 中央云台继续使用 PA3/PA6/PA7，中央 AS5600 使用 PC6。
- 储球圆盘独立使用 PC7/PC8/PC9，储球圆盘 AS5600 使用 PA1。
- 超声波 M 调整为 PA4/PA5；未来 R 预留 PC10/PC11。
- PC7～PC11 与板载 OV 摄像头/SD 卡接口复用。本车使用外置 K210 时，不插板载 OV 摄像头和 SD 卡。
